# 晚安成电服务器签到 🌙

众所周知，**晚安成电** 现在的登录需要用 **在 微信环境 的 wx.login()** 来获取 **code**，然后才能去获得 **ticket** 来登录，所以一些现有的方案会有 **请到 微信小程序 签到** 的提示，直接给这些方案 送钟 了（

所以我大概学习了一下 **小程序逆向**，大概找到了 **两种 解决方案**。两种方案 都经过了 **实际验证**，应该不会有太大的问题

当然，如果还有别的更好方案，也欢迎到 [Issues]([Issues · MilLoong/UESTC-NightSign-Server](https://github.com/MilLoong/UESTC-NightSign-Server/issues)) 来给出您的意见

两种方案都以 **晚安成电签到** 为目标，区别在于 **获取微信登录凭证** 的方式

> **注**：
>
> 1. **经纬度配置**：两种方案 都需要提供 本人实际签到位置 的 **经度、纬度**，使用 **GCJ-02（高德／腾讯地图）** 坐标，并确保位于 学校允许的签到范围 内
>
>    - **交给 Agent 部署（推荐）**：复制 对应方案 的 部署 Prompt，并补充 `我的经度是 <你的经度>，纬度是 <你的纬度>，请写入私密配置`。Agent 会将坐标写入 目标环境，无需 提前修改源码
>    - **方案一手动填写**：将 `wechat-runtime/config.example.json` 复制为 `config.json`，把 经度 填入 `longitude`、纬度 填入 `latitude`，保留 `coordinateSystemCode` 为 `gcj02`。部署时将 该文件 放入调试容器的 `/work/night-sign/config.json`，仅修改 本地示例文件 不会改变 容器内配置
>    - **方案二填写**：由 Agent 在 补齐签到业务入口 时 创建位置配置，并告知 实际文件路径。服务器 或 本地模式 写入 私密配置，GitHub Actions 模式写入 工作流约定 的 Secret，不要直接修改 `login_replay/protocol.py` 等协议代码
>    - **占位值说明**：示例中的 `0` 仅用于展示 配置格式，必须替换为 自己的坐标。经度 和 纬度 不要填反，真实位置配置 不要提交到 公开仓库
>
> 2. 本项目最好有 **服务器 运行环境**，不限定 云服务商
>
>    方案二也可使用 **GitHub Actions**，不需要 自备常驻服务器，**首次 微信会话 采集** 仍需在 **兼容的 微信环境** 完成
>
>    如果 没有 服务器，可以在 **本地电脑部署**，或 自行准备一台服务器，执行 定时任务 时需保持 设备开机 且 网络可用
>
>    （不过有可能 **本地部署** 的方案更好？因为 后端 可能会 **检查 IP**？）

## 方案一：服务器运行微信 🖥️

**原理**：服务器运行 **Linux 微信**，登录并打开 **成电智慧学工**，通过 **调试桥** 调用 **目标小程序** 的 `wx.login()`，用 `code` 和学校登录态换取 `ticket`，再向 **晚安成电** 的 `daily-checkin` 接口提交签到

- **优点**：使用 **真实微信运行时**，已验证 服务器取码、学校票据兑换 及 真实签到，不依赖 重放快照 的 持续有效性
- **缺点**：微信 需要 **常驻**，资源占用 较高，登录失效 需要 人工处理，微信升级 可能需要 适配调试器
- **目录**：[wechat-runtime](wechat-runtime/)，提供取码、学校授权、范围 及 时间检查、单次签到 和 每日定时任务

**部署 Prompt**：[打开并复制](wechat-runtime/PROMPT.md)

## 方案二：采集会话后重放请求 🌐

**原理**：首次 在 **已登录微信** 中采集 **成功登录请求 及 解密所需 的 会话状态**，之后 服务器 直接 **重放请求**，从 **微信响应** 中取得 `code`，再完成学校 `ticket` 兑换 和 **晚安成电签到**，日常运行 **无需微信常驻**

- **优点**：资源占用低，日常运行 **无需桌面环境**，支持服务器、本地部署或 **GitHub Actions** 定时运行
- **缺点**：首次采集 **依赖兼容 的 微信环境**，**会话失效** 后需要 重新采集，不能保证 永久有效
- **目录**：[session-replay](session-replay/)，基于 开源协议逻辑 重构，保留 MIT 许可，当前提供 重放取码 及 离线测试

**部署 Prompt**：[打开并复制](session-replay/PROMPT.md)
